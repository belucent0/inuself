# 💭 개발 고려 중인 항목

### Linux 기반 GPU 가속 ASR 워커 지원

Linux 환경에서 GPU 가속을 활용한 ASR(+화자분리) 워커 지원

**고려사항:**
- Docker 컨테이너화
- ROCm의 WSL 지원시 우선 순위 상향 
- Linux 환경 ROCm 설정 및 테스트

---

### ASR 전사 정확도 LLM 후처리

ASR 결과를 LLM으로 후처리하여 전사 정확도 향상

**고려사항:**
- LLM 후처리 파이프라인 설계
- 처리 속도 및 정확도 고려한 LLM 모델 선택
- 정확도 개선을 위한 측정 기준 수립
- 파인 튜닝을 통한 후처리 전문 LLM 모델 구성

---

### 음성 프로필을 통한 화자 인식

화자의 음성 프로필을 학습으로 화자 자동 인식 기능 제공

**고려사항:**
- 사용자별 음성 프로필 학습으로 화자 매칭
- 프로필 저장 및 관리 시스템
- 실시간 화자 인식 성능

---

### 요약 등의 LLM 처리시 NPU 가속

LLM 처리 시 NPU 가속을 통한 병렬 채널 증대 및 효율성 향상

**도입 목표:**
- 병렬 채널 증대: 동시 처리 가능한 작업 수 증가
- 저전력: GPU 대비 낮은 전력 소비로 운영 비용 절감
- 저발열: 낮은 발열로 시스템 안정성 향상 및 냉각 비용 절감
- 안정성: 장시간 운영 시 안정적인 성능 유지

**고려사항:**
- NPU 하드웨어 호환성
- 가속 라이브러리 선택
- 성능 벤치마크 (처리량, 전력 효율, 안정성)
- 구현 복잡도 평가

---

### 실시간 ASR 스트리밍

실시간 오디오 스트림을 받아 즉시 전사 결과를 반환하는 스트리밍 API 제공

**고려사항:**
- WebSocket 또는 Server-Sent Events (SSE) 기반 스트리밍 프로토콜 선택
- 저지연 실시간 처리 파이프라인 설계
- 오디오 청크 버퍼링 및 처리 최적화
- 동시 연결 수 관리 및 리소스 제한
- 에러 처리 및 재연결 메커니즘
- 스트리밍 상태 모니터링 및 로깅

---

### 영어 ASR 및 요약 콘텐츠

영어 음성 파일에 대한 ASR 전사 및 LLM 기반 요약 기능 제공

**고려사항:**
- 영어 ASR 모델 선택 및 통합
- 다국어 지원 파이프라인 설계
- 영어 콘텐츠에 최적화된 LLM 요약 프롬프트
- 언어 자동 감지 및 처리 모드 전환
- 영어 전사 정확도 검증 및 개선

---

### ASR 처리 진행률 표시 기능

ASR 처리 중 실시간 진행률 및 상태 정보를 사용자에게 제공하는 기능

**고려사항:**
- WebSocket 또는 Server-Sent Events (SSE)를 통한 실시간 진행률 전송
- 처리 단계별 진행률 표시 (오디오 로딩, ASR 처리, 화자분리, 요약 등)
- 예상 완료 시간 계산 및 표시
- 처리 중인 청크/세그먼트 정보 표시
- 에러 발생 시 상세 정보 제공
- 클라이언트 UI에 프로그래스 바 및 상태 표시 구현
