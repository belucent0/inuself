# 💭 개발 고려 중인 항목

### Linux 기반 GPU 가속 ASR 워커 지원

Linux 환경에서 GPU 가속을 활용한 ASR(+화자분리) 워커 지원

**고려사항:**
- Docker 컨테이너화
- ROCm의 WSL 지원시 우선 순위 상향 
- Linux 환경 ROCm 설정 및 테스트

---

### 음성 프로필을 통한 화자 인식

화자의 음성 프로필을 학습으로 화자 자동 인식 기능 제공

**고려사항:**
- 사용자별 음성 프로필 학습으로 화자 매칭
- 프로필 저장 및 관리 시스템
- 실시간 화자 인식 성능

---

### 실시간 스트리밍 화자분리

실시간 ASR 스트리밍에 화자분리 기능 통합

**고려사항:**
- 실시간 화자 임베딩 추출 및 클러스터링
- 지연 시간과 정확도 간 균형
- 화자 수 동적 감지

---

### 영어 ASR 및 요약 콘텐츠

영어 음성 파일에 대한 ASR 전사 및 LLM 기반 요약 기능 제공

**고려사항:**
- 영어 ASR 모델 선택 및 통합
- 다국어 지원 파이프라인 설계
- 영어 콘텐츠에 최적화된 LLM 요약 프롬프트
- 언어 자동 감지 및 처리 모드 전환
- 영어 전사 정확도 검증 및 개선

---

### ASR 처리 진행률 표시 기능

ASR 처리 중 실시간 진행률 및 상태 정보를 사용자에게 제공하는 기능

**고려사항:**
- WebSocket 또는 Server-Sent Events (SSE)를 통한 실시간 진행률 전송
- 처리 단계별 진행률 표시 (오디오 로딩, ASR 처리, 화자분리, 요약 등)
- 예상 완료 시간 계산 및 표시
- 처리 중인 청크/세그먼트 정보 표시
- 에러 발생 시 상세 정보 제공
- 클라이언트 UI에 프로그래스 바 및 상태 표시 구현

---

### 묵음 구간 감지 및 제안

분석된 오디오 파형을 기반으로 묵음(Silence) 구간을 자동 탐지하여 삭제 또는 건너뛰기를 제안하는 기능

**고려사항:**
- **묵음 탐지 알고리즘**: 오디오 데이터를 분석하여 일정 데시벨 이하의 지속적인 묵음 구간 식별
- **사용자 제안 UI**: 식별된 묵음 구간을 시각적으로 표시하고, 사용자에게 일괄 삭제 또는 개별 처리 제안
- **처리 효율성**: 대용량 오디오 파일에 대한 클라이언트 측 분석 성능 최적화

---

### LLM 기반 화자 분리 후처리

기존 알고리즘 기반 화자 분리(Diarization) 결과의 오차를 보정하고, 화자 구분의 정확도를 극대화하기 위해 LLM을 후처리에 도입

**고려사항:**
- **화자 교체 지점 보정**: LLM의 문맥 이해 능력을 활용하여 화자가 바뀌는 시점의 미세한 부정확성 보정
- **화자 일관성 검증**: 대화 전체의 흐름을 분석하여 화자 식별 오류(예: 화자 A를 B로 오인) 자동 탐지 및 수정
- **다화자 대화 최적화**: 3인 이상 다화자 대화에서의 화자 분리 성능 강화 방안 모색
