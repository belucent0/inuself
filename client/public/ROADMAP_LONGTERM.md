# 🎯 장기 도전 과제

### ASR 처리시 NPU 가속

ASR 처리 시 NPU 가속을 통한 병렬 채널 증대 및 효율성 향상

**도입 목표:**
- 병렬 채널 증대: 동시 처리 가능한 음성 채널 수 증가
- 저전력: GPU 대비 낮은 전력 소비로 운영 비용 절감
- 저발열: 낮은 발열로 시스템 안정성 향상 및 냉각 비용 절감
- 안정성: 장시간 연속 처리 시 안정적인 성능 유지

**도전 과제:**
- NPU 기반 ASR 엔진 개발 지원원
- 기존 GPU 가속과의 성능 비교 (처리량, 전력 효율, 안정성)
- 하드웨어 의존성 최소화
- 멀티 플랫폼 지원

**예상 기간:** 장기 (6개월 이상)

### Whisper 모델의 경량화

Whisper 모델의 크기 및 연산량 최적화를 통한 경량화

**도전 과제:**
- 모델 양자화 기법 적용
- 다국어 지식 증류 (Knowledge Distillation) 검토
- 한국어 전문 파인 튜닝
- 정확도 손실 최소화
- 추론 속도 개선

**예상 기간:** 장기 (6개월 이상)
