# 🔨 현재 개발 중인 항목

### ASR 청킹 오버랩 후처리

ASR 처리 시 청킹된 결과의 오버랩 부분을 후처리하여 정확도 향상

**목표:**
- 청킹된 ASR 결과의 오버랩 구간 처리 로직 개선
- 전사 정확도 향상
- 문맥 일관성 유지

### .pdf 및 .docx 문서 파일의 요약 및 뷰어 기능

문서 파일 업로드 및 LLM 기반 요약, 뷰어 기능 제공

**목표:**
- PDF 및 DOCX 파일 업로드 지원
- 문서 내용 추출 및 파싱
- LLM을 활용한 문서 요약 기능
- 문서 뷰어 UI 구현

---

낮은 품질의 음성 파일 처리 시 발생하는 환각 현상 제거 및 후처리

- 저품질 음성 구간 감지 및 안내내
- ASR 환각 현상 패턴 분석
- 후처리 알고리즘 개발
- 정확도 개선 검증

### GPU 자원 스케줄링 및 락 관리 최적화

한정된 온디바이스 GPU 자원을 여러 종류의 워커(ASR, LLM 등)가 경합할 때 발생하는 에러 및 데드락 방지를 위한 락 관리 최적화

**목표:**
- Redis 분산 락 로직 개선으로 워커 간 자원 경합 제어 및 데드락 방지
- Celery 워커 큐 기반 작업 스케줄링 최적화
- 오디오 길이 기반 동적 락 TTL 계산 로직 개선
- 워커별 GPU 자원 접근 순서 및 우선순위 관리
- 락 회복 메커니즘 강화 (워커 강제 종료 시 자동 복구)
