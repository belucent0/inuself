# 🔨 현재 개발 중인 항목

### ASR 청킹 오버랩 LLM 정밀 후처리

ASR 청킹 시 발생하는 오버랩 구간을 별도로 추적하고, 해당 구간에 대해 LLM을 활용한 정밀 후처리를 수행하여 연결 부위의 정확도와 자연스러움을 향상

**목표:**
- **오버랩 구간 추적**: 청킹 시 중첩되는 구간의 데이터를 정확히 식별하고 보존(Memory)
- **LLM 기반 후처리**: 식별된 각 오버랩 구간을 LLM에 할당하여 문맥 기반 최적화 및 보정 수행
- **문맥 연결성 강화**: 전/후 텍스트와의 매끄러운 연결을 보장하여 끊김 없는 고품질 전사 결과 도출

---

### 다중 이미지 스토리텔링 및 심층 분석

업로드된 다중 이미지의 순서를 기반으로 개별 분석 및 전체적인 맥락을 파악하여 스토리라인과 인사이트를 제공

**목표:**
- **업로드 및 정렬**: 최대 5장의 이미지 다중 선택 및 모달 창 내 사용자 지정 순서 재배치 기능
- **개별 분석**: 각 이미지별 OCR 및 묘사(Portray) 처리를 통한 상세 정보 추출
- **통합 인사이트**: 이미지 간 연관 관계 분석, 전체 스토리 요약 및 심층 인사이트 도출


---

### Whisper ASR 신뢰도 기반 환각 제거 및 LLM 후처리

Whisper ASR 수행 시 추출된 신뢰도(Confidence Score)를 기반으로, 부정확한 구간을 식별하고 LLM을 활용하여 문맥에 맞게 보정

**목표:**
- **신뢰도 추출**: Whisper 모델의 Log Probability 등을 활용한 ASR 정확도/신뢰도 값 추출
- **환각/오류 식별**: 신뢰도가 낮은 구간 및 환각(Hallucination) 의심 패턴 감지 로직 개발
- **LLM 후처리**: 감지된 오류 구간에 대해 LLM을 활용한 문맥 기반 교정 및 후처리 기능 구현
- **정확도 향상**: 원문과 교정문 비교를 통한 최종 전사 정확도 검증

### 음성 파일 시각화

음성 파일 업로드 시 프론트엔드에서 파형(Waveform)을 시각화하여 음량 높낮이를 직관적으로 표시

**목표:**
- **오디오 시각화**: Web Audio API 및 Canvas 등을 활용하여 업로드 된 오디오 파일의 파형 및 음량 높낮이 시각화
- **UI 연동**: 업로드 모달 내에서 재생 및 탐색 시 파형 동기화

---


### GPU 자원 스케줄링 및 락 관리 최적화

한정된 온디바이스 GPU 자원을 여러 종류의 워커(ASR, LLM 등)가 경합할 때 발생하는 에러 및 데드락 방지를 위한 락 관리 최적화

**목표:**
- Redis 분산 락 로직 개선으로 워커 간 자원 경합 제어 및 데드락 방지
- ASR, LLM, OCR 워커 큐 기반 작업 스케줄링 최적화
- 오디오 길이 기반 동적 락 TTL 계산 로직 개선
- 워커별 GPU 자원 접근 순서 및 우선순위 관리
- 락 회복 메커니즘 강화 (워커 강제 종료 시 자동 복구)

---

### 콘텐츠 테이블 정규화 및 구조 개선

불필요한 데이터 중복을 제거하고, 확장성 있는 구조로 콘텐츠 관련 데이터베이스 테이블 정규화 진행

**목표:**
- **테이블 분리**: Content 테이블에서 메타데이터, 파일 정보 등 성격이 다른 컬럼 분리 및 관계 설정
- **데이터 무결성 강화**: 외래 키 제약 조건 및 데이터 타입 최적화로 무결성 보장
- **확장성 확보**: 추후 다양한 콘텐츠 타입 추가에 유연하게 대응할 수 있는 스키마 설계

### Whisper v3 모델 8비트 양자화 적용 및 모델 선택

Whisper v3 Large 모델의 8비트 양자화 버전을 도입하여 메모리 효율성을 확보하고, 사용자가 작업 목적에 맞춰 모델을 선택할 수 있도록 지원

**목표:**
- **8비트 양자화 적용**: v3 Large 모델의 8-bit Quantization을 통해 온디바이스 GPU 메모리 사용량 최적화
- **모델 선택 인터페이스**: 파일 업로드 시 사용자가 사용할 ASR 모델(v3 8bit, v2 등)을 선택할 수 있는 옵션 제공
- **성능 벤치마킹**: 양자화 전후의 정확도 및 처리 속도 비교 분석
