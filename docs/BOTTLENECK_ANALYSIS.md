## 개선 방안

### 1. CPU-GPU 데이터 전송 최적화 (최우선) ⭐

#### 현재 상태:
- `non_blocking=True` 이미 적용됨
- 하지만 pyannote 내부에서 순차 처리로 인해 효과 제한적

#### 개선 방안:

**A. 배치 크기 증가 (이미 테스트 완료, 효과 미미)**
- Segmentation/Embedding 배치 크기 증가
- 결과: 32 → 128로 증가해도 효과 없음

**B. 오디오 청크 크기 조정**
- pyannote가 내부적으로 오디오를 청크로 나누어 처리
- 더 큰 청크 = 더 적은 전송 횟수
- **테스트 필요**: pyannote 파이프라인 설정 확인

**C. 비동기 파이프라인**
- 다음 청크를 미리 로드하여 전송과 연산 오버랩
- **구현 복잡도**: 높음 (pyannote 내부 구조 수정 필요)

**D. CUDA Stream 활용**
- 여러 CUDA 스트림을 사용하여 전송과 연산 병렬화
- **구현 복잡도**: 중간

### 2. MIOpen 최적화

#### 현재 설정:
- `MIOPEN_FIND_MODE = FAST` (Mode 8)
- `MIOPEN_DISABLE_CACHE = '1'` (캐시 비활성화)
- `torch.backends.cudnn.benchmark = True`

#### 추가 최적화 가능성:
- **NORMAL 모드 테스트**: 더 최적의 커널 찾기 (느릴 수 있음)
- **캐시 활성화**: 첫 실행 후 재실행 시 빠름 (이미 테스트 완료, 효과 있음)
