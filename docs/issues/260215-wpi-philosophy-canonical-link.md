# WPI 철학 문서 위치 확정 기록

**날짜**: 2026-02-15  
**상태**: 완료

## 결정

- WPI 해석 철학/원칙 문서는 `docs/issues`가 아닌 `docs/personal`을 canonical 위치로 사용한다.
- 이슈 문서는 타임라인/의사결정 로그 역할로만 유지하고, 본문은 canonical 문서로 링크한다.

## Canonical 문서

- `docs/personal/05-wpi-philosophy-and-interpretation-principles.md`

## 이유

- `docs/issues`는 장애/회고/작업 추적 중심이며 시간순 로그 성격이 강함.
- WPI 철학 문서는 재사용 가능한 장기 기준 문서이므로 도메인 문서 영역(`docs/personal`)이 적합함.
